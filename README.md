#  Changement climatique

## Présentation

Ce projet consiste à réaliser un **site web consacré au changement climatique**.

L'objectif est de présenter de manière simple et accessible les principales notions liées au changement climatique, ses causes, ses conséquences ainsi que les enjeux environnementaux actuels.

Ce projet a également permis de mettre en pratique les notions de **développement web** étudiées en cours.

---

##  Objectifs du projet

* Comprendre et présenter les principaux enjeux du changement climatique.
* Créer une interface web claire et accessible.
* Structurer des informations à l'aide de données XML.
* Ajouter des interactions avec JavaScript.
* Mettre en pratique HTML et CSS pour la création et la mise en forme des pages.

---

##  Technologies utilisées

* **HTML5** — Structure des pages web
* **CSS3** — Mise en forme et design
* **JavaScript** — Interactions et fonctionnalités dynamiques
* **XML** — Organisation et gestion des données

---

##  Fonctionnalités

Le site permet notamment de :

* consulter différentes informations sur le changement climatique ;
* naviguer entre les différentes parties du site ;
* présenter des contenus structurés ;
* utiliser des données provenant d'un fichier XML ;
* interagir avec les éléments de la page grâce à JavaScript.
